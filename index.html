Safari Media Grabber v4.0

Find publicly accessible media on webpages, inspect HLS playlists, select quality and audio, download in chunks, then merge locally in Safari.

Limitations: No DRM, access-control, CORS, or iframe security bypass. Bookmarklet detection is best-effort. Safari Web Inspector can expose requests a bookmarklet cannot. Only save content you are allowed to keep. HLS and local merging run in-browser; YouTube jobs run on your private server and temporarily store media there.

When an iframe blocks the bookmarklet, capture its requests using Safari's Develop → Show Web Inspector → Network. Start playback, then export a HAR file if your Safari version offers the option; otherwise copy the Network request URLs or request details and paste them below. Keep signed URLs private, and import them promptly because they can expire.
